This is an unofficial, evidence-based Proxy-Seller guide. It explains the main product types and the search terms people commonly use when comparing them:

- **Static residential IP / ISP proxy:** a stable residential-class IP allocated through an internet service provider. It can fit long sessions, a consistent regional identity, SEO monitoring, and ad verification.
- **Residential proxy:** an address from a residential IP pool, with country, city, and ISP targeting plus rotating or sticky sessions.
- **IPv4 proxy:** a static datacenter proxy with broad website compatibility.
- **IPv6 proxy:** a lower-cost option with a large address space; confirm that the target website supports IPv6 before buying.
- **Mobile proxy:** an address from a 4G or 5G carrier network for tasks that need a mobile-network environment.

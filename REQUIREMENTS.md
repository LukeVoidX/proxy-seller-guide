# Proxy-Seller Guide — Requirement Baseline

## Outcome

Create a useful, search-readable, unofficial Proxy-Seller guide that helps a buyer choose a proxy type, understand the checkout flow, and use Luke's verified promo codes.

## Scope and non-goals

- Publishable GitHub README plus English and Chinese GitHub Pages surfaces.
- Cover IPv4, IPv6, ISP, residential, and mobile proxy categories at a practical level.
- Show LUKE25 and LUKEFANS with their exact discount, scope, and validity.
- Include dated merchant-checkout evidence and affiliate disclosure.
- Do not claim to be Proxy-Seller's official repository.
- Do not repeat unverified network-size, speed, review, price, refund, or success-rate claims found in competing affiliate pages.
- Do not publish, create a remote repository, or enable GitHub Pages in this review slice.

## Acceptance evidence

- Both language pages render locally without horizontal overflow at desktop and mobile widths.
- Promo-code copy controls work and present a visible status message.
- Canonical, hreflang, Open Graph, FAQ structured data, sitemap, and robots directives point to the planned GitHub Pages URLs.
- README exposes the key offer facts and links to the full guide.
- Local link and HTML checks pass.

## Constraints and risks

- GitHub Pages URL is assumed to be `https://lukevoidx.github.io/proxy-seller-guide/`; confirm at publication.
- Prices change by product, quantity, location, and term, so the guide sends readers to live pricing instead of hard-coding a price table.
- LUKE25 is time-limited; the page must present LUKEFANS as the durable fallback.
- All affiliate relationships are disclosed next to purchase actions and in the footer.

## Version and delivery impact

- New repository, initial local version `0.1.0`.
- Delivery profile: managed GitHub Pages.
- This slice ends at a verified local preview. Remote repository creation and publication require Luke's explicit approval after review.
